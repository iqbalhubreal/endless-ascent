THE ENDLESS CLIMB - SPLIT PROJECT

Files
-----
index.html   Main page markup and the Three.js import map.
styles.css   All page and interface styles.
js/app.js    Three.js scene, animation, sound, camera, and recording logic.

How to run
----------
1. Extract the complete folder while preserving the js subfolder.
2. Open the folder in VS Code.
3. Run index.html with Live Server, or serve the folder through a local HTTP server.
4. Keep an internet connection available because Three.js is loaded from the CDN.

Do not move app.js out of the js folder unless you also update the script path in index.html.
